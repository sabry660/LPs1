🏋️ FORGED — 3D Immersive Gym Experience

Train. Eat. Dominate.

FORGED is a futuristic 3D fitness website built using Three.js + HTML/CSS/JavaScript in a single file.
Designed with a dark industrial brutalist aesthetic, FORGED combines immersive WebGL visuals, animated workout systems, nutrition tools, and interactive gym education into one cinematic experience.
